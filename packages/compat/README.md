# @native-surface/compat

Compat shims for [`native-surface`](https://github.com/ryanlanciaux/native-surface):
high-level, boundary-general stand-ins for React Native community packages
that need engine wiring (gesture-handler, safe-area-context, expo modules,
mmkv, keyboard-controller, …). Installed automatically as a dependency of
`native-surface`; the Vite preset aliases package imports here — you should
never need to import it directly.
